## 5. New Scripts Added

### `run_all_pipelines.sh`
Runs `run_compositional_pipeline.py --skip-contracts` for every JSON in a contracts folder. Default target: `contracts/enabled_pgd/`. Reads `onnx_path` directly from each JSON. Outputs to `results/compositional/<folder_basename>/<stem>/`.

### `run_bab_1000_contracts.sh`
Batch BaB-only runner for the five 100%-accurate NNs. Mirrors `run_pgd_1000_contracts.sh` but passes `--no-pgd`. Outputs to `contracts/disabled_pgd/<name>.json`.

## Pending Work

### PGD disabled vs. enabled comparison (overnight run)

**Goal:** Paired comparison of CROWN results across all five 100%-accurate NNs, with PGD on and off, at identical 60s BaB timeout.

**Rationale for 60s timeout:** Scientifically cleaner than 10s — same time budget, one variable (PGD on/off). Average SAT contract time with PGD enabled was ~5.9s on ThinkPad, well within 60s. With BaB-only, UNSAT contracts will timeout regardless of budget (HPC runs have shown no convergence after hours).

**Expected result:** BaB-only will produce mostly TIMEOUT for UNSAT contracts; PGD-enabled will show SAT/UNSAT with zero timeouts. This demonstrates PGD is essential for resolving UNSAT contracts efficiently.

**To run overnight:**
```bash
cd REPRODUCIBILITY/2026_TBA/examples/grid_world
./run_bab_1000_contracts.sh
```

After run: use `run_all_pipelines.sh contracts/disabled_pgd/` to run the nuXmv step on the new BaB-only contracts for the full comparison table.
